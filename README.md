## 🇨🇳 中文说明

这是一个用于南洋理工大学（NTU）电子与电气工程学院（EEE）**硕士学位论文（Master's Dissertation）**的 LaTeX 模板。

本模板基于前几届同学已有的版本进行了更新和维护，**并已由作者本人成功使用该模板通过了 NTU EEE 学院 2026 年秋季学期的官方格式审核**。特此开源分享，希望能帮助后续的硕士同学减轻排版负担。

### 🚀 如何使用
1. 点击右上角 `Code` -> `Download ZIP` 下载，或直接克隆本仓库。
2. 使用 LaTeX 编辑器（推荐 Overleaf 或本地安装的 TeX Live / MacTeX）打开 `main.tex` 文件。
3. 修改 `main.tex` 中的论文信息（如标题、姓名、学号、导师等）。
4. 编译生成 PDF 即可。

## 🇬🇧 English Description

A LaTeX template for the NTU School of Electrical and Electronic Engineering (EEE) **Master's Dissertation**.

This template is updated and maintained based on previous students' versions. **It has been successfully used by the author to pass the official NTU EEE format check for the Fall 2026 semester.** It is shared here to help future Master's students save time on formatting.

### 📌 Changelog
* Synchronized with the latest NTU EEE dissertation guidelines (**as of October 2026**).
* Fixed various compilation warnings and errors from previous versions.
* Adjusted specific parts (e.g., cover page, TOC, bibliography format) to meet the latest format check standards.

### 🚀 How to Use
1. Click `Code` -> `Download ZIP`, or clone this repository.
2. Open `main.tex` with a LaTeX editor (Overleaf or a local TeX Live / MacTeX installation is recommended).
3. Modify the thesis information in `main.tex` (e.g., title, name, matriculation number, supervisor).
4. Compile to generate the PDF.
